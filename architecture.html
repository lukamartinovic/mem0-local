mem0-local Architecture

Self-hosted Mem0 memory layer — fully local, no cloud, no data leaves the machine

IDE Integration

  • • MCP HTTP transport at localhost:8765/mcp
  • • 9 tools: add/search/get/update/delete memory
  • • Works with Cursor, Claude Code, Codex, Windsurf, VS Code
  • • No lifecycle hooks (agent self-manages via system prompt)

MCP Server (Docker)

  • • Python 3.12 + mem0ai 2.0.11
  • • Auto-chunking (model-aware: 1.5K–8K chars)
  • • Context headers on chunks for document attribution
  • • LLM diagnostic on silent failures (actionable errors)
  • • Self-test on every startup (9 tools)
  • • Dimension mismatch auto-fix (768-dim)

Ollama (Host — GPU)

  • • Runs natively for Metal GPU acceleration
  • • LLM: qwen2.5:7b (tool calling required)
  • • Embedder: nomic-embed-text (768 dims)
  • • setup.sh model picker detects RAM, offers 5 models
  • • Not in Docker — avoids CPU emulation

Qdrant (Docker)

  • • Vector database for memory storage
  • • Persistent volume (survives restarts)
  • • 768-dimension collections
  • • Auto-deletes stale collections on dimension mismatch

Privacy & Telemetry

  • • MEM0_TELEMETRY=False (PostHog disabled)
  • • Zero external network calls
  • • No API keys, no cloud services
  • • All data stays on host machine
  • • No code content sent anywhere
